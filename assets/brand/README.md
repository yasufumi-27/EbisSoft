# ブランド素材（ロゴ・名刺）

印刷・資料用の素材です。**サイトには配信されません**（`public/` の外に置いてあります）。

ロゴの文字は、画面のロゴ（`src/components/site/CompanyLogo.tsx`）とまったく同じ
Geist Black の輪郭（`src/components/fx/logoFont.json`）から起こしています。名刺と画面でロゴがずれません。

| 種類 | 正データ | 直し方 |
| --- | --- | --- |
| ロゴ単体 | `logo/*.svg`（PNGはその書き出し） | `python3 scripts/brand-assets.py` で作り直す |
| 名刺 | `meishi/meishi.html` | **このHTMLを手で書き換える**（スクリプトは触りません） |

## ロゴ単体 — `logo/`

| ファイル | 中身 | 使いどころ |
| --- | --- | --- |
| `yebisu-soft-mark.svg` / `.png` | マークのみ（**背景透過**・正方形 2048px） | 資料の隅、印章的な使い方 |
| `yebisu-soft-mark-navy.svg` / `.png` | マークのみ（ネイビーの角丸地・2048px） | SNSのアイコン、アプリアイコン |
| `yebisu-soft-logo-horizontal-onlight.svg` / `.png` | マーク＋ワードマーク（**背景透過**／`YEBISU` はネイビー・2600px） | 白・薄い色の紙面、白背景のスライド |
| `yebisu-soft-logo-horizontal-ondark.svg` / `.png` | マーク＋ワードマーク（ネイビー地／`YEBISU` は白・2600px） | 濃色背景のスライド、封筒 |

ワードマークは `YEBISU`（白またはネイविー）＋ `SOFT`（シアン `#22d3ee`）。
**社名の英字表記を使ってよいのはロゴだけ**で、本文・見出しはカタカナの「エビスソフト」です。

## 名刺 — `meishi/meishi.html`

**この1ファイルが名刺の元データです。**社員が増えたり、メールを載せる／載せないを切り替えたりを
手作業でやる前提なので、あえてHTML1枚にまとめてあります（画像ではないので文字を直接直せます）。

- 仕上がり **91 × 55mm**（日本の標準サイズ）
- **裁ち落とし（塗り足し）各3mm** 込みで 97 × 61mm
- 文字は仕上がりから4mm内側（安全枠）に収めてあります
- ロゴはインラインSVG（実データ）なので、拡大しても滲みません

### 編集のしかた

ブラウザで開いて確認しながら、テキストエディタで同じファイルを直します。

| やりたいこと | やり方 |
| --- | --- |
| 文字を変える | `<p>` などの中身を書き換えるだけ。大きさ・位置は先頭の `<style>` で決まります |
| メールを載せない | `<span class="mail">` を `<span class="mail hidden">` にする（行ごと消してもOK） |
| 社員を増やす | `<section class="card front">〜</section>` を丸ごとコピーし、「ここから下が人ごとに変わるところ」の氏名・肩書・連絡先だけ直す。裏面は共通なので1枚でよい |
| 携帯番号を足す | `.contact` の中に `<p>` を1行足す。**折り返すと氏名に重なる**ので1行に収めること |

画面には赤い線（仕上がり）と青い破線（安全枠）が出ます。**印刷には出ません。**
文字は必ず青い破線の内側に置いてください。

### 印刷・入稿

ブラウザで ⌘P（印刷）→ 用紙サイズ「カスタム **97 × 61mm**」／余白なし／
「背景のグラフィック」をON／拡大縮小100% → PDFで保存。**そのまま入稿できます**
（`@page` で用紙サイズを指定してあるので、実測 97.03 × 61.04mm のPDFが出ます。表・裏の2ページ）。

- 和文は `Hiragino Sans` などシステムフォント参照です。PDFにすれば埋め込まれるので入稿先の環境を問いません。
- 色はRGBです。CMYK指定を求められたら、ネイビー `#0f2e5f`／シアン `#22d3ee`／赤 `#a51f38` を
  近似値に変換してもらってください。
- QRコードは入れていません。必要なら追加できます。
- 掲載内容を変えたら、サイト側（`src/lib/site.ts`・`src/lib/author.ts`）と食い違わないか確認してください。
